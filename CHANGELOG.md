# Changelog

Todos los cambios notables de este proyecto serán documentados en este archivo.

El formato está basado en [Keep a Changelog](https://keepachangelog.com/es-ES/1.0.0/),
y este proyecto adhiere a [Semantic Versioning](https://semver.org/lang/es/).

## [3.0.0] - 2025-11

### Añadido
- Sistema completo de gestión de inventario de material
- Gestión de materiales con categorías y ubicaciones
- Sistema de movimientos de entrada/salida con albaranes
- Sistema de firmas digitales (emisor y receptor)
- **Firma móvil remota con SSE (Server-Sent Events)**
- Peticiones públicas de material con formulario web
- **Mapa interactivo de almacenes con Leaflet.js**
- Dashboard con KPIs y estadísticas
- Sistema de notificaciones (email y push)
- PWA (Progressive Web App) instalable
- Sistema de proyectos con tareas
- Gestión multi-almacén con filtrado por usuario
- Sistema de backups y restauración
- Solicitudes de reposición de stock
- Sistema de auditoría completo
- Configuración SMTP múltiple
- Campos personalizados configurables

### Cambiado
- Migración a Laravel 11
- Migración a Vue.js 3 con Composition API
- Actualización a PHP 8.3
- Mejoras en la interfaz de usuario con Tailwind CSS

### Mejorado
- Optimización de consultas a base de datos
- Mejoras en la experiencia de usuario
- Sistema de notificaciones más robusto
- Mejoras en la generación de PDFs

## [2.0.0] - 2024-XX

### Añadido
- Versión inicial del sistema
- Gestión básica de materiales
- Sistema de movimientos básico

- **Añadido**: Nueva funcionalidad
- **Cambiado**: Cambios en funcionalidad existente
- **Deprecado**: Funcionalidad que será eliminada
- **Eliminado**: Funcionalidad eliminada
- **Corregido**: Corrección de bugs
- **Seguridad**: Correcciones de seguridad
