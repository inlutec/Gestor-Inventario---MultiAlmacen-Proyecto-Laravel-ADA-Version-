# Logos institucionales

Coloca aquí los ficheros PNG oficiales para que aparezcan en la interfaz:

- junta-logo.png  
  - Recomendado: fondo transparente, alto 32–48px (la interfaz lo muestra a 24–32px en header/footer).
- ada-logo.png  
  - Recomendado: fondo transparente, alto 32–48px (la interfaz lo muestra a 24–32px en header/footer).

Si los ficheros no existen, la interfaz oculta automáticamente la imagen y mantiene el texto.
